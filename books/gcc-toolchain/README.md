# From compiler to toolchain

Begin with [a program from two files](chapters/01-a-program-from-two-files.md).
Two small functions let us ask what an object leaves unfinished, how a linker
finishes one call, and who supplies the process's first instruction.

This volume's entrance selects the LP64, AMD64 System V, object-output
profile at the [shared source edition](../EDITION.md). You can follow it on
paper without building TinyCC, completing the entire legacy compiler, or
repeating the seed-byte audit. The complete shared compiler and runtime
mechanisms remain required production components and have explicit later
teaching homes.

and unexecuted; the later units are not yet manuscript chapters. G01 supplies
the entrance contracts, not complete object, ABI, linker, or runtime coverage.
